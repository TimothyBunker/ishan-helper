# Exam Preparation Guide

This guide details how to extract, index, merge, and query your lecture slides in `./slides` to support fast, accurate, and concise answers on your exam—using only slide content and professor terminology.

## Objective
- Enable rapid lookup of slide excerpts during the exam
- Ensure answers strictly reference slide material (no external or overly advanced content)

## Prerequisites
- Python 3.x
- PyPDF2 library (`pip install PyPDF2`)
- A `/slides` directory containing your course PDFs

## Available Scripts
All scripts live in the `scripts/` directory.

1. **Index slides** (`index_slides.py`)
   - Extracts per-page text from each PDF into `slide_index.json`.
   - Usage:
     ```bash
     python3 scripts/index_slides.py \
       --dir slides \
       --out slide_index.json
     ```

2. **Query slides** (`query_slides.py`)
   - Searches `slide_index.json` for a keyword or phrase and returns matching snippets with filename and page numbers.
   - Usage:
     ```bash
     python3 scripts/query_slides.py \
       "search term" \
       --index slide_index.json \
       --max-results 5
     ```

3. **Concatenate text** (`concat_slides_text.py`)
   - Builds a single text file (`all_slides.txt`) containing every slide’s content, grouped by filename and page.
   - Usage:
     ```bash
     python3 scripts/concat_slides_text.py \
       --index slide_index.json \
       --out all_slides.txt
     ```

4. **Merge PDFs** (`merge_pdfs.py`)
   - Merges all slide PDFs into one file (`all_slides.pdf`) for easy browsing.
   - Usage:
     ```bash
     python3 scripts/merge_pdfs.py \
       --dir slides \
       --out all_slides.pdf
     ```

## Workflow Summary
1. Update or confirm slide PDFs:
   ```bash
   ls slides/
   ```
2. Index your slides:
   ```bash
   python3 scripts/index_slides.py -d slides -o slide_index.json
   ```
3. (Optional) Review all text:
   ```bash
   python3 scripts/concat_slides_text.py -i slide_index.json -o all_slides.txt
   ```
4. (Optional) Browse combined PDF:
   ```bash
   python3 scripts/merge_pdfs.py -d slides -o all_slides.pdf
   ```
5. Look up content during exam:
   ```bash
   python3 scripts/query_slides.py "relevant term" -i slide_index.json
   ```

## Tips for Exam
- Use exact headings or keywords found in slides for precise matches.
- Cite the slide filename and page number in your answers (e.g., `slide1.pdf – page 10`).
- Increase `--max-results` if needed to see more context.
- Keep answers concise and grounded in slide text—aim for clarity over depth.
